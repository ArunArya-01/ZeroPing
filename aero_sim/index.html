AeroFlux

An Aviation Physics-Informed Machine Learning Framework for Fuel-Flow Prediction

Watch a trained model predict fuel burn for every segment of a real flight — rendered live on a 3D globe. A physics baseline plus machine learning, distilled into a compact neural network that runs right in your browser.

How it works

01

Physics Baseline

OpenAP estimates fuel flow from aircraft type, true airspeed, altitude, vertical rate, and mass — an interpretable first-principles model.

02

Residual Learning

Gradient-boosted models (XGBoost, LightGBM, CatBoost) learn the gap between physics and reality — sparse telemetry, missing air-data, unknown aircraft mass.

03

Distillation

The frozen ensemble teacher trains a compact MLP student that runs in-browser via ONNX Runtime Web — no server needed.

What the simulation shows

An animated aircraft following a real great-circle route
Segments colored by predicted fuel burn
A live 3D fuel gauge that depletes in real time
Route picker, playback speed & camera controls
